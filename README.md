# Tattler Restaurant Directory
A platform to provide personalized restaurant recommendations using MongoDB for data storage and Express.js for a RESTful API.

## Installation
1. Clone the repository: `git clone https://github.com/anacasx_Tattler.git`
2. Install MongoDB locally or use MongoDB Atlas.
3. Run data import scripts: `node scripts/import.js`

## Repository Structure
- /data: MongoDB backup files
- /scripts: Data import scripts
- /screenshots: Database and import screenshots
