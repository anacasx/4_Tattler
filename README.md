# Tattler Restaurant Directory
A platform to provide personalized restaurant recommendations using MongoDB to store data in a schema with address, cuisine, grades, and comments, and Express.js for a RESTful API.

## Installation
1. Clone the repository: `git clone https://github.com/your-username/tattler-restaurant-directory.git`
2. Install MongoDB locally or use MongoDB Atlas.
3. Run data import scripts: `node scripts/import.js`

## Repository Structure
- /data: MongoDB backup files and CSV data
- /scripts: Data import scripts
- /screenshots: Database and import screenshots

## Version
Current version: 1.0.0 (Initial database setup with schema)
